# AETHER OFFICE: guidance for coding agents

This file is the shared rule index for every AI coding agent working in this repository (`CLAUDE.md` points here). Humans
should read [CONTRIBUTING.md](CONTRIBUTING.md) and [docs/development.md](docs/development.md).

## Non-negotiable rules

- Do not run a paid model, push, open a remote pull request, merge automatically, edit global configuration or bypass a
  permission prompt without explicit authorization from the maintainer.
- Protect user data. Demo, fixture, observed, replay and live data stay distinct and labeled. Never log or print secrets.
- Keep attribution: upstream agent-office is MIT; see `NOTICE` and `docs/legal/provenance.md`. Do not copy code from
  projects with incompatible licenses ([licence policy](docs/legal/licence-policy.md)). After changing dependencies run
  `pnpm run notices` (`THIRD_PARTY_NOTICES.md` is generated).
- Never claim production readiness from a green build. Implementation and verification are separate fields in
  `docs/verification/features.json`; a check that was not run is not "passed".

## Architecture boundaries

`apps/{control,runner,web}` and `packages/{contracts,kernel,providers,office-scene}`. The kernel has no transport, database or
UI dependencies; the runner never writes the control database; the web app has no Node imports. `pnpm lint` enforces these.
See [docs/architecture.md](docs/architecture.md).

## Checks

Run before finishing: `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, `pnpm test`, `pnpm build`, and
`pnpm exec playwright test` (the same ones CI runs). Work test-first.

## UI

Follow [docs/design-system.md](docs/design-system.md): values come from `apps/web/src/styles/core/tokens.css`, shared pieces from
`apps/web/src/ui/` (one module per piece), rules go in the stylesheet file of the thing they style. A UI change is done when the responsive and
accessibility specs pass and the changed pages were looked at on a phone-sized and a tablet-sized screen.

## Characters

Animals are generated by `tools/blender`. After changing an animation, a proportion or the desk, run
`tools/blender/audit_animals.py` (it must report no clipping), rebuild the models and run `node scripts/validate-assets.mjs`.
See [docs/development.md](docs/development.md#the-animals).

## Conventions

Conventional commit prefixes (`feat`, `fix`, `refactor`, `perf`, `docs`, `test`, `chore`, `ci`). Small focused changes. Prefer
the standard library and existing code over new dependencies. Record user-visible changes in `CHANGELOG.md`.
