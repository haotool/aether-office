## Ideas studied, not code

Other open-source projects informed the design (see [docs/research](docs/research/README.md)): their approaches to session
observation, process lifecycle, terminal-state detection, retry and stall handling, and atomic file creation. Where a project's
license restricts reuse (AGPL-3.0, source-available or custom riders), no code was taken. Ideas from MIT and Apache-2.0
projects were re-implemented here.

- `node-pty` (Microsoft, MIT) and `@xterm/xterm` (MIT) provide terminals; `@xyflow/react` (MIT) the task graph; `@a2a-js/sdk` and

  better-sqlite3, Zod and the other packages retain their own licenses.

## Assets

The animal models, textures and animations are generated by the scripts in `tools/blender` and are original to this project. No
external font, texture, HDR image or model file is bundled.

A distributable software bill of materials has not been produced yet and is a release gate (see
[docs/development.md](docs/development.md#releasing)).
