# 任務依賴圖

任務頁有列表、看板與依賴圖。箭頭由前置任務指向後續工作；圖中使用控制台 snapshot 的任務及依賴資料，不從聊天文字猜測進度。可縮放、顯示完整圖，並以滑鼠或鍵盤開啟任務詳情。詳情另有文字版前置依賴與狀態。

owner／operator 可在第一次派工前，修改 ready／backlog 任務的前置依賴。後端驗證 expectedVersion、同專案引用、遺失節點、重複依賴與循環，通過後才一起更新依賴、版本、狀態及事件。全部前置任務 completed 時為 ready，否則為 backlog；已派工、執行過或終止的任務不能改寫依賴歷史。Agent 沒有修改既有依賴的權限。

圖形本身是可檢視的唯讀連線，修改透過任務詳情的表單完成。操作不會直接啟動模型。新增／修改依賴的事件保留依賴 ID，方便追溯。

取消任務會在同一交易取消依賴鏈中未執行過、尚在等待的後續任務；菱形依賴不重複取消。後續任務保存 cancelCause、版本與各自事件。已執行過或仍有執行紀錄的工作不會被覆寫，取消中的遲到成功也不會復活後續任務。取消不會自動復原依賴鏈，若需繼續應明確重新規劃工作。

目前仍待完成 workflow templates、跨 provider reviewer/fix 路徑、公平排程與完整訊息等待的取消連動。此依賴圖不是上述整套協作工作流的完成證明。
